# EdgePair Labs

**Practical Edge AI**

EdgePair Labs builds practical Edge AI software that delivers high performance on low-cost hardware.

We focus on bringing machine learning directly to edge devices, where data is generated and real-time decisions need to be made.

## What We Do

- **Edge AI** — Run AI inference directly on devices without relying on the cloud.
- **Computer Vision** — Detect objects, events, and movements from live video.
- **Efficient Models** — Optimize machine learning models for limited CPU, GPU, and memory resources.
- **Real-Time Processing** — Turn continuous video and sensor streams into useful events and actions.
- **On-Device Privacy** — Keep data and computation close to where it is created.

## Our Approach

We believe useful AI should not require expensive hardware or a constant cloud connection.

Our focus is on the complete path from machine learning model to practical edge application:

**Model → Optimization → Edge Device → Real-Time Application**

The goal is simple:

> **High-performance AI on affordable, everyday hardware.**

## First Product

### Snooker Clip

[Snooker Clip](https://play.google.com/) is our first application of Edge AI technology.

It uses computer vision and on-device AI to automatically detect and capture snooker shots in real time.

Key features include:

- Automatically captures every shot
- Real-time cue ball tracking
- Built-in scoreboard
- Automatic highlight creation
- Fast local video processing
- 100% local processing

Snooker Clip is designed to run smoothly on everyday Android devices, including entry-level hardware.
